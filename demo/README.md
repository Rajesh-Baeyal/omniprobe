# OmniProbe walkthrough video

[`omniprobe-demo.mp4`](omniprobe-demo.mp4) is a 34-second, 1280×720 H.264 product-tour video for the buildathon submission. It follows the redesigned operator-console experience:

1. Command Center and deterministic telemetry
2. Frame Studio packet inspection
3. Virtual Bus controlled fault injection and Logic Scope
4. Learning Studio, Calculator Lab, and Recipe Manager
5. Safety & Cyber defensive boundaries

The video is a deterministic visual walkthrough rather than a browser or hardware recording. It contains no credentials, live transport, exploit tooling, or machine-specific paths.
