# OmniProbe demo video

`omniprobe-demo.mp4` is a short, deterministic product-tour video for the buildathon submission. It presents the Command Center, Frame Studio, Virtual Bus chaos controls, Register Matrix, Logic Scope, and Commissioning Doctor flow.

The public static demo is intended to be paired with the live URL:

```text
https://rajesh-baeyal.github.io/omniprobe/
```

The video does not include credentials, hardware payloads, or machine-specific paths.
